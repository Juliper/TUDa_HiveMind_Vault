# Konjugation - Verben

|**Present Polite**|masustem + ます|masustem + ません|
|---|---|---|
|**Past Polite**|masustem + ました|masustem + ませんでした|
|**Past Informal**|ta form|Nai-Form - い + かった|
|**Present Continuous**|te-Form + いる/います|te-form +|

### Verbstems

**Godan-Masustem:** う→い く→き す→し つ→ち ぬ→に む→み ぐ→ぎ ぶ→び る→り

**Ichidan-Masustem**

いる→ (einfach る weg) える→ (einfach る weg)

**Ausnahmen die auch Godan sind**

入る、切る、走(hashi)る、いる、 帰(kae)る、限(kagi)る、喋(shabe)る、知(shi)る、蹴(ke)る、滑(sube)る

### Nai-Form (Negation)

**Godan:** う→わない く→かない す→さない つ→たない ぬ→なない む→まない ぐ→がない ぶ→ばない る→らない

**Ichidan:**

いる/える→ ない

**Ausnahmen**

くる→にない する→しない ある→ない

### Te/Ta-Form

う、つ、る→って/た む、ぬ、ぶ→んで/だ く→いて/た ぐ→いで/だ す→して/た

Ausnahmen:

いく→いって/た くる→きて/た する→して/た

# Grammatik

- Willst du x ? (Höfliche Einladung) → ～ませんか。
- Da ist Y. / Ich habe → X が　あります/います。
- Da drüben ist X. → あそこに X が あります。
- X ist Präposition Y. → X はＹの Präposition です。
- (Adjektive) i-Adjektiv / na-adjektiv mit na + noun
- X mag (nicht) Y. → X は Y が　すき/きらいです。
- Lass uns. →~ましょ。
- Sollen wir? / Soll ich? (Auch Hilfe anbieten) → ～ましょか。
- Bitte → ～て　ください。
- Sequenz von Events → ～て ~ます。
- Sequenz von Adjektiven → ~て, ~て, … あつい　です。
- Du darfst ...? → ～て　もいい(です)。
- Darf ich→ ～て　もいい(ですか)。
- Verbote → ～て　は(wa)いけません。
- X deswegen Y (Sätze verbinden) → X です、から　Yです。
- Begründung geben (Weil X) → Xです　から。
- Ich mache gerade X → ～ている。/ ~ています。
- Zustände → ～ている。/ ~ています。
- Ich habe gemacht → ～ていました。
- Leute beschreiben
    - X hat eine Mütze auf. → Xは　ぼうしを　かぶっています。 (Auf den Kopf tragen)
    - X trägt eine Brille. → Xは　めがねを　かけています。(Brille)
    - X trägt eine Hose. → Xは　ジーンズを　はいています。(Unter der Hüfte tragen)
    - X trägt ein Shirt. → Xは　Tシャツを　きています。(Über der Hüfte anziehen)
    - X hat lange Haare. → Xは　かみが　ながいです。

---

- Gehen und machen → Ort に Verb (in masu Form aber ohne masu) に いく。
- Kommen und machen → Ort に Verb (in masu Form aber ohne masu) に くる。
- Zurückkehren und machen → Ort に Verb (in masu Form aber ohne masu) に かえる。
- Komm bitte zu mir und X → Ort ni Verb (in masu Form aber ohne masu) ni kite kudasai

---

- X lebt in Y. → X は Y に すんでいます。
- X macht Y. → X は Y を しています。
- X arbeitet in Y → X は Y で はたらいています。

# Lesson 8

- 読まないでください。 (Bitte nicht lesen) -u wird zu i
- 食べないでください。(Bitte nicht esse)
- こないでください。(Bitte nicht gehen)
- Xのが　好きですか。(Magst du X (X in Wörterbuchform))
- **だれが〜です/ますか。→　Xさんが〜です/ますか。**
- Xと　思います。 (Ich denke dass … wobei X short form ist)

# Lesson 9

- Kurzformen (Vergangenheit) → ～た／～なかった。
- Informelle Rede (Kurzformen in gesprochener Sprache).
- Indirekte Rede/Zitate → ～と言いました／～と思いました。
- Bitte nicht … → ～ないでください。
- X の が好き／上手 etc. → Verb (Wörterbuchform) の が Adjektiv です。
- Subjektpartikel → が betont „wer/was“.
- Etwas/Nichts → 何か／何も + Negation。

# Lesson 10

- Vergleich zwischen zwei Dingen → A のほうが B より Adjektiv です。
- Superlativ → グループの中で A が いちばん Adjektiv です。
- Absicht/Plan → ～つもりだ (Verb Kurzform)。
- Werden/Veränderung → Adjektiv／Nomen + なる。
- Irgendwo / nirgends → どこか に／どこ に も + Negation。

# Lesson 11

- Aufzählung beispielhafter Handlungen → ～たり ～たり する。
- Erfahrung → Verb (Vergangenheit Kurzform) ことがある。
- Nomen-Aufzählung locker → Noun A や Noun B など。

# Lesson 12

- Erklärung/Begründungs-Nuance → ～んです／～のです。
- Zu viel → ～すぎる (Stamm + すぎる)。
- Ratschlag → ～ほうがいい です。
- Weil → ～ので。
- Müssen → ～なければいけません／～なきゃ (informell)。
- Höfliche Vermutung/Bestätigung → ～でしょう（か）。
