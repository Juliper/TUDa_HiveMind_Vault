# Lesson 1

- X ist Y → X は Y です。
- Y von X → X (Einschränkung) の Y (Thema)

# Lesson 2

- X ist nicht Y → X は Y じゃない (です)。

# Lesson 3

- Willst du x ? (Höfliche Einladung) → ～ませんか。

# Lesson 4

- Da ist Y. / Ich habe → X が　あります/います。
- Da drüben ist X. → あそこに X が あります。
- X ist Präposition Y. → X はＹの Präposition です。

# Lesson 5

- X mag Y. → X は Y が　すきです。
- Lass uns. →~ましょ。
- Sollen wir? / Soll ich? → ～ましょか。

# Lesson 6

- Bitte → ～て　ください。
- Sequenz von Events → ～て ~ます。
- Sequenz von Adjektiven → ~て, ~て, … あつい　です。
- Darf Ich ...? → ～て　もいい(です)。
- Du darfst …? → ～て　もいい(ですか)。
- Verbote → ～て　は(wa)いけません。
- X deswegen Y (Sätze verbinden) → X です、から　Yです。
- Begründung geben (Weil X) → Xです　から。

# Lesson 7

- Ich mache gerade X → ～ている。/ ~ています。
- Zustände → ～ている。/ ~ています。
- Ich habe gemacht → ～ていました。
- Leute beschreiben
    - X hat eine Mütze auf. → Xは　ぼうしを　かぶっています。 (Auf den Kopf tragen)
    - X trägt eine Brille. → Xは　めがねを　かけています。(Brille)
    - X trägt eine Hose. → Xは　ジーンズを　はいています。(Unter der Hüfte tragen)
    - X trägt ein Shirt. → Xは　Tシャツを　きています。(Über der Hüfte anziehen)
    - X hat lange Haare. → Xは　かみが　ながいです。
- Gehen und machen → Ort に Verb (in masu Form aber ohne masu) に いく。
- Kommen und machen → Ort に Verb (in masu Form aber ohne masu) に くる。
- Zurückkehren und machen → Ort に Verb (in masu Form aber ohne masu) に かえる。
- Komm bitte zu mir und X → Ort ni Verb (in masu Form aber ohne masu) ni kite kudasai
- X lebt in Y. → X は Y に すんでいます。
- X macht Y. → X は Y を しています。
- X arbeitet in Y → X は Y で はたらいています。

# Lesson 8

- 読まないでください。 (Bitte nicht lesen) -u wird zu i
- 食べないでください。(Bitte nicht esse)
- こないでください。(Bitte nicht gehen)
- Xのが　好きですか。(Magst du X (X in Wörterbuchform))
- **だれが〜です/ますか。→　Xさんが〜です/ますか。**
- Xと　思います。 (Ich denke dass … wobei X short form ist)
