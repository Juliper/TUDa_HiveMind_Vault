## Aufgabe 2/3/5 - Fragen vervollständigen und beantworten

> [!question] Beschreibung
> Fragen beantworten. Antworten sind nicht vorgegeben - man muss selbst die Zeichen kennen und schreiben koennen.

> [!question] Beschreibung
> Richtige Antwort zu einer Frage auswaehlen. Die Antworten sind gegeben.

> [!question] Beschreibung
> Fragesaetze vervollstaendigen mit 吗 (ma), 哪里 (nali), 哪 (na), 什么 (shenme) und 呢 (ne)
> 
> 吗 (ma) := Aussagesatz + ma ist eine Ja/Nein Frage
> 
> 哪里 (nali)/哪 (na)/什么 (shenme) := Erstzen in einem Satz die Antwort. Also wenn man auf solche Sätze antwortet nali und na mit der Antwort ersetzen.
> 
> 呢 (ne) := Ist kurze Rückfrage am Ende des Satzes. 你呢 (ni ne / und du)，她呢 (ta ne / und er)


X = Name, 他，她，你

| Mögliche Fragen                                                               | Mögliche Antworten                                                                                                     |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Fragen über Namen**                                                         |                                                                                                                        |
| 我叫X。你呢？<br>wo jiao X。ni ne？<br>Ich bin X. Und du?                             | 我叫X。<br>wo jiao X。<br>Ich bin X (voller Name).                                                                         |
| X叫什么名字？<br>X jiao shenme mingzi？<br>Wie heißt X?<br>                          | X叫Y。<br>X jiao Y。<br>X heißt Y.                                                                                        |
| X姓什么？<br>X xing shenme？<br>Wie ist X Nachname?                                | X姓Y。<br>X xing Y。<br>X heißt Y (Nachname).                                                                             |
| X的中文名字是什么？<br>X de zhongwen mingzi shi shenme？<br>Wie heißt X auf chinesisch? | X的中文名字是Y。<br>X de zhongwen mingzi shi Y。<br>X chinesischer Name ist Y.                                                 |
|                                                                               |                                                                                                                        |
| **Fragen über Herkunft**                                                      |                                                                                                                        |
| X是日本人吗？<br>X shi ribenren ma？<br>Ist X Japaner?                               | 是，X是日本人。/ 不是，X是德国人。<br>shi, X shi ribenren。/ bu shi, X shi deguoren。<br>Ja, X ist Japaner. / Nein, X ist Deutscher.    |
| X是哪国人？<br>X shi na guo ren？<br>Aus welchem Land ist X?                        | X是德国人。<br>X shi deguoren。<br>X ist Deutscher.                                                                          |
| X是哪里人？<br>X shi nali ren？<br>Von wo ist X?                                    | X是柏林人。<br>X shi bolinren。<br>X ist aus Berlin.                                                                         |

| **Fragen über Wohnort**                                                       |                                                                                                                        |

| X住在Y吗？<br>X zhu zai Y ma？<br>Wohnt X in Y?                                    | 是，X住在Y。/ 不，X住在Z。<br>shi, X zhu zai Y。/ bu, X zhu zai Z。<br>Ja, X wohnt in Y. / Nein, X wohnt in Z.                     |

| X在哪里工作？<br>X zai nali gongzuo？<br>Wo arbeitet X?                              | X在医院工作。/ X在大学工作。<br>X zai yiyuan gongzuo。/ X zai daxue gongzuo。<br>X arbeitet im Krankenhaus. / X arbeitet an der Uni. |
|                                                                               |                                                                                                                        |
| **Allgemeine Ja/Nein-Fragen**                                                 |                                                                                                                        |
| X是Y吗？<br>X shi Y ma？<br>Ist X Y?                                              | 是，X是Y。/ 不是，X不是Y。<br>shi, X shi Y。/ bu shi, X bu shi Y。<br>Ja, X ist Y. / Nein, X ist nicht Y.                          |
