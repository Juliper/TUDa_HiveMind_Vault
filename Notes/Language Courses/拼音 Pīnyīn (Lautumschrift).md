> [!IMPORTANT]
**拼音** (Pīnyīn) ist die offizielle lateinische Lautumschrift für Mandarin-Chinesisch. Jede chinesische Silbe wird durch **Anlaut + Auslaut + Ton** beschrieben.
>
> Hier gibt es eine Interaktive Pinyin-Tabelle mit Aussprache: https://studycli.org/de/pinyin-chart/

## Silbenstruktur

$$\text{Silbe} = \underbrace{\text{Anlaut (声母)}}_{\text{optional}} + \underbrace{\text{Auslaut (韵母)}}_{\text{pflicht}} + \underbrace{\text{Ton (声调)}}_{\text{1–4 oder neutral}}$$

- Der **Anlaut** (Shēngmǔ) ist ein Konsonant am Silbenanfang
- Der **Auslaut** (Yùnmǔ) ist der vokalische Rest der Silbe (ein oder mehrere Vokale, ggf. mit -n oder -ng)
- Der **Ton** bestimmt die Bedeutung: gleiche Silbe + anderer Ton = anderes Wort

## Töne (声綢 shēngdiào) - vier Töne + neutraler Ton

| Ton     | Zeichen | Verlauf              |
| ------- | ------- | -------------------- |
| 1. Ton  | ā       | hoch, gleichbleibend |
| 2. Ton  | á       | steigend             |
| 3. Ton  | ǎ       | trief-fallend        |
| 4. Ton  | à       | scharf fallend       |
| Neutral | a       | kurz                 |

> [!NOTE]
> Der 3. Ton wird in der Praxis oft nur als **tiefer, fallender Ton** gesprochen. Vor einem anderen 3. Ton wird er zum **2. Ton**: 你好 = ní hǎo (nicht nǐ hǎo).

## Anlaute (声母 Shēngmǔ) - 21 Konsonanten

|               | Unaspiriert | Aspiriert | Nasal | Sonstige      |
| ------------- | ----------- | --------- | ----- | ------------- |
| **Labial**    | b [p]       | p [pʰ]    | m [m] | f [f]         |
| **Alveolar**  | d [t]       | t [tʰ]    | n [n] | l [l]         |
| **Velar**     | g [k]       | k [kʰ]    |       | h [x]         |
| **Palatal**   | j [tɕ]      | q [tɕʰ]   |       | x [ɕ]         |
| **Retroflex** | zh [tʂ]     | ch [tʂʰ]  |       | sh [ʂ], r [ɻ] |
| **Dental**    | z [ts]      | c [tsʰ]   |       | s [s]         |

> [!IMPORTANT]
> **Aspiriert** bedeutet mit Luftstoß: **p**, **t**, **k**, **q**, **ch**, **c** werden behaucht gesprochen. Die unaspirierten **b**, **d**, **g**, **j**, **zh**, **z** klingen für deutsche Ohren fast wie stimmlose Konsonanten (nicht wie deutsches b/d/g).

## Aussprache-Besonderheiten

Pinyin-Schreibung weicht an vielen Stellen von der tatsächlichen Aussprache ab. Die wichtigsten Fälle:

### Auslaute, die anders klingen als geschrieben

| Geschrieben | Gesprochen | Beispiel | Erklärung |
|---|---|---|---|
| **-ian** | **-ien** | tiān → "tien" | Das a wird zu einem e |
| **-ian** nach j/q/x | **-ien** | jiān → "jien" | |
| **-üan** | **-üen** | yuán → "yüen" | Gleiche Regel mit ü |
| **-un** | **-uen** | lùn → "lüen" | Verstecktes e |
| **-ui** | **-uei** | huí → "huei" | Verstecktes e |
| **-iu** | **-iou** | liú → "liou" | Verstecktes o |
| **-e** (alleinstehend) | **[ɤ]** | gē → dunkles "gö" | Kein deutsches "e" |
| **-e** nach i/ü | **[ɛ]** | jiě → offenes "e" wie dt. "Bett" | Anderer Laut als oben |

### Anlaute, die anders klingen als erwartet

| Geschrieben | Gesprochen | Hinweis |
|---|---|---|
| **c** | [tsʰ] | Wie dt. "Z" in "Zahn", aber mit Hauch |
| **q** | [tɕʰ] | Wie "tch" mit Hauch, **nicht** wie dt. "Q" |
| **x** | [ɕ] | Wie "sch" aber weiter vorne (zwischen "s" und "sch") |
| **zh** | [tʂ] | Wie "dsch" retroflex (Zunge zurückgerollt) |
| **ch** | [tʂʰ] | Wie "tsch" retroflex, mit Hauch |
| **sh** | [ʂ] | Wie "sch" retroflex |
| **r** | [ɻ] | Wie englisches "r" in "run", retroflex |
| **j** | [tɕ] | Wie "dsch" aber weiter vorne, **nicht** wie engl. "j" |

### Schreibregeln, die den Laut verbergen

| Regel | Beispiel | Eigentlich |
|---|---|---|
| **ü → u** nach j, q, x | ju, qu, xu | jü, qü, xü (ü-Laut!) |
| **ü → u** nach y | yu | yü |
| **i → yi** ohne Anlaut | yī | i + 1. Ton |
| **u → wu** ohne Anlaut | wǔ | u + 3. Ton |
| **ü → yu** ohne Anlaut | yǔ | ü + 3. Ton |

> [!WARNING]
> Die häufigste Falle: **ju, qu, xu** enthalten den **ü-Laut** [y], nicht den u-Laut [u]! Also: 去 qù = "tɕʰü", nicht "tɕʰu".

## Tonzeichen-Platzierung

Das Tonzeichen steht immer auf dem **Hauptvokal** der Silbe. Merkregel:

1. Gibt es ein **a** oder **e** → Ton darauf: hǎo, méi
2. Gibt es **ou** → Ton auf das **o**: dǒu
3. Sonst → Ton auf den **letzten Vokal**: liú, guì
