## Nützliche Kurzphrasen

| Hànzì | Pīnyīn | Deutsch |
|---|---|---|
| 是 | shì | Ja / Sein |
| 不是 | bú shì | Nein / Nicht sein |
| 好 | hǎo | Gut / OK |
| 好的 | hǎo de | In Ordnung |
| 不好 | bù hǎo | Nicht gut |
| 对 | duì | Richtig / Stimmt |
| 不对 | bú duì | Falsch / Stimmt nicht |

> [!NOTE] Tipp
> Die Partikel 吗 (ma) am Satzende verwandelt eine Aussage in eine Ja/Nein-Frage:
> - 你好 → 你好吗？ (Wie geht es dir?)
> - 他是老师 → 他是老师吗？ (Ist er Lehrer?)
