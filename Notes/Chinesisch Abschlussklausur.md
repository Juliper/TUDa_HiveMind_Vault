## Aufgabe 1 - Töne erkennen

> [!info] Beschreibung
> Richtige Ton zu einer Silbe auswählen. Es wird ein Sound gegeben und dann vorgegebenen Pinyin (ohne Ton) den richtigen Ton hinzuzeichnen.

> [!Important] Markerplatzierung
> Wenn ein Wort mehrere Vokale hat kommt der Marker in dieser Priorität auf die Vokale:
> a > o > e > i > u > ü

| Ton     | Zeichen | Verlauf              |
| ------- | ------- | -------------------- |
| 1. Ton  | ā       | hoch, gleichbleibend |
| 2. Ton  | á       | steigend             |
| 3. Ton  | ǎ       | tief-fallend         |
| 4. Ton  | à       | scharf fallend       |
| Neutral | a       | kurz                 |

> [!NOTE] Tipp
> Coole Webseite um Aussprachen zu erkennen:

## Aufgabe 3 - Zeichen in die richtige Reihenfolge bringen

> [!info] Beschreibung
> Vorgegebene Hanzi müssen in einen Satz gebracht werden.
### Mögliche Satzstrukturen:

> [!tip] Allgemeine Grundformel (die "Master-Reihenfolge")
> **Subjekt + Zeit + (在) Ort + Adverb (都/也/不) + Modalverb (要) + Verb + Objekt**

> [!Important] Bei Adressen oder beim Datum immer von groß nach klein

> [!Important] Bei Sätzen die Alter, Datum, Zeit oder Preis ausdrücken kann das Verb weggelassen werden

> [!Important] Zeit kann vor (betont, am Satzanfang, vor dem Subjekt) oder nach (normal, nach dem Subjekt, aber vor dem Verb) dem Subjekt kommen

#### Modalverben

| Modalverb | Pinyin | Bedeutung                                                   | Beispiel                           |
| --------- | ------ | ----------------------------------------------------------- | ---------------------------------- |
| 要         | yào    | wollen / müssen (Notwendigkeit, auch nahe Zukunft "werden") | 我要喝茶 (ich möchte/will Tee trinken) |
#### Adverbien

| Modalverb | Pinyin | Bedeutung | Beispiel |
| --------- | ------ | --------- | -------- |
| 不         |        |           |          |

#### Subjekt + Adverb + Adjektivprädikat

| 1. Satzteil     | 2. Satzteil | 3. Satzteil |
| --------------- | ----------- | ----------- |
| 你（nǐ）           | 真 (zhen)    | 好（hǎo）      |
| 我（wǒ）           | 很（hěn）      | 忙（máng）     |
| 我哥哥（wǒ gēge）    | 不（bù）       | 忙           |
| 爸爸妈妈（bàba māma） | 都很（dōu hěn） | 好           |
#### Subjekt  + Verbalprädikat (+ Objekt）
| 1. Satzteil  | 2. Satzteil | 3. Satzteil   |
| ------------ | ----------- | ------------- |
| 我哥哥（wǒ gēge） | 喝（hē）       | 茶（chá）        |
| 我（wǒ）        | 是（shì）      | 德国人（déguórén） |

#### Subjekt + Adverb + Verbalprädikat + Objekt

| 1. Satzteil | 2. Satzteil | 3. Satzteil | 4. Satzteil |
| ----------- | ----------- | ----------- | ----------- |
| 他（tā）       | 不（bù）       | 是（shì）      | 老师（lǎoshī）  |
|             | 也（yě）       |             |             |
|             | 都（dōu）      |             |             |
|             | 都不（dōu bú）  |             |             |
|             | 也不（yě bù）   |             |             |
> [!Important] Zwei Funktionen von 给 (gěi)
> 1. **给 als Hauptverb** ("geben"): nimmt selbst zwei Objekte → ...给 + Person + Sache (Struktur unten links)
> 2. **给 als Coverb/Präposition** ("für/an jmd."): steht vor einem *anderen* Hauptverb und leitet den Empfänger ein → ...给 + Person + Verb + Objekt (Struktur unten rechts)

#### (Zeit kann auch am Anfang stehen) + Subjekt + Zeit + MV + 给 (Verb "geben") + Objekt 1 (Person) + Objekt 2 (Sache)

| 1. Satzteil | 2. Satzteil  | 3. Satzteil | 4. Satzteil | 5. Satzteil | 6. Satzteil                     |
| ----------- | ------------ | ----------- | ----------- | ----------- | ------------------------------- |
| 我 （wǒ）      | 明天（míngtiān） | 可以（kěyǐ）    | 给（gěi）      | 你 （nǐ）      | 我的电话号码<br>（wǒ de diànhuà hàomǎ） |
#### (Zeit kann auch am Anfang stehen) + Subjekt + Zeit + MV + 给 (Coverb "für/an") + Objekt 1 (Person) + Verb + Objekt 2

| 1. Satzteil | 2. Satzteil | 3. Satzteil | 4. Satzteil | 5. Satzteil | 6. Satzteil | 7. Satzteil |
| ----------- | ----------- | ----------- | ----------- | ----------- | ----------- | ----------- |
| 你（nǐ）       | 现在（xiànzài） | 可以（kěyǐ）    | 给（gěi）      | 我 （wǒ）      | 打（dǎ）       | 电话（diànhuà） |
| 你（nǐ）       | 现在（xiànzài） | 要 (yào)     | 给（gěi）      | 我 （wǒ）      | 打（dǎ）       | 电话（diànhuà） |

#### Subjekt + zài + Ort + Verb +（Obj）

| 1. Satzteil | 2. Satzteil | 3. Satzteil | 4. Satzteil | 5. Satzteil |
| ----------- | ----------- | ----------- | ----------- | ----------- |
| 我 （wǒ）      | 在（zài）      | 家（jiā）      | 喝（hē）       | 茶（chá）      |

#### Einladungen / Aufforderungen (Pivotsatz 兼语句) - Subjekt + Verb1 + Objekt (= zugleich Subjekt von Verb2) + Verb2 + Objekt2

> [!Important] 请 vs. 叫: 请 (qǐng) = höflich einladen/bitten; 叫 (jiào) = auffordern/jmd. sagen, etwas zu tun (weniger höflich, kann auch "rufen" bedeuten). Die Person nach 请/叫 ist gleichzeitig Objekt des 1. Verbs UND Subjekt des 2. Verbs.

| 1. Satzteil | 2. Satzteil | 3. Satzteil | 4. Satzteil        |
| ----------- | ----------- | ----------- | ------------------ |
| 我 （wǒ）      | 请 (qing)    | 他（tā）       | 吃中餐 (chi zhongcan) |
| 我 （wǒ）      | 叫 (jiao)    | 他（tā）       | 吃中餐 (chi zhongcan) |

## Aufgabe 7 - Fragepronomen

> [!info] Beschreibung
> Sätze umformen mit 吗 (ma), 哪里 (nali), 哪 (na), 什么 (shenme) 呢 (ne) und 几 （jī）
> 
> 吗 (ma) := Aussagesatz + ma ist eine Ja/Nein Frage
> 
> 哪里 (nali) / 哪 (na) / 什么 (shenme) / 谁 (shei)  := Erstzen in einem Satz die Antwort. Also wenn man auf solche Sätze antwortet nali und na mit der Antwort ersetzen.
> 
> 呢 (ne) := Ist kurze Rückfrage am Ende des Satzes. 你呢 (ni ne / und du)，她呢 (ta ne / und er).
> 
> 多大 (duoda) := Am Ende des Satzes um nach Alter des Subjekts zu fragen.
> 
> 多傻 (duosha) := Am Ende eines Satzes um nach Telefonnummern, Raumnummern zu fragen
> 
> 几号 (ji hao) := Welches Datum?
> 
> 星期几 := Welcher Tag?


### Beispiele

* 这个周末你有时间吗？
* 你有什么计划？
* 看什么电影？
* 几点？
* 怎么样？
* 可以吗？
* 新期六做什么？
* 你叫什么名字？
* 我做什么工作？
* 你在哪里工作？
