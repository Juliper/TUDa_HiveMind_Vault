> [!NOTE] Definition
> Visual attention determines which parts of the visual field are processed in detail. It operates in three distinct modes.

## Types of Attention

| Type | German | Description |
|------|--------|-------------|
| **Selective** | Gewahlt | Deliberately focusing on one thing among multiple options |
| **Divided** | Geteilt | Attempting to focus on multiple things simultaneously (multitasking) |
| **Captured** | Erfasst | An external stimulus involuntarily captures all attention |

## Early Perception Features

The visual system processes certain features pre-attentively (before conscious attention):

- Color
- Orientation
- Movement
- Size
- Lighting / Shading

## Related Phenomena

- **Change Blindness**: failure to notice large changes in a scene, possibly related to attention allocation
- **Stroop Effect**: interference when stimulus and response are incompatible (e.g., reading the word "RED" printed in blue ink)
- **Vection**: illusory self-motion caused by moving visual fields

- [[Human-Machine Interface]]: attention as part of the perception-decision-reaction loop
