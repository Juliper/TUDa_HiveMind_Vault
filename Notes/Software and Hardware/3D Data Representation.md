> [!NOTE] Definition
> 3D data representation covers the primitives, transformations, and input methods used to describe three-dimensional scenes in computer graphics.

## Graphic Input

- Generation of 3D models (procedural or manual)
- Sampling of real objects (scanning)

## Primitives

The basic building blocks of 3D geometry:
- **Points**
- **Lines**
- **Triangles** (most common polygon primitive)

## Geometric Transformations

| Transformation | Description |
|---------------|-------------|
| Translation | Moving an object |
| Rotation | Rotating an object |
| Scaling | Enlarging or shrinking |
| Shearing | Skewing along an axis |
