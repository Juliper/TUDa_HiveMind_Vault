> [!NOTE] Definition
> Heuristic evaluation is an analytical usability evaluation method in which experts inspect an interface and judge it against a set of established usability principles (heuristics), without involving real users.

## Advantages

- **Quick and cheap** compared to running a user study
- **Few ethical and practical issues** to consider, since no users are involved
- Experts bring existing **knowledge of the application domain and typical users**

## Problems

- Can be difficult and expensive to find qualified experts
- Important problems can still be **missed**, since no real user ever interacts with the system
- Tends to surface **many trivial problems** alongside genuinely important ones
- Experts carry their own **biases**, which can shape which issues they notice

## Analytical Evaluation Wrap-Up

Heuristic evaluation belongs to the family of **analytical evaluation methods** - relatively inexpensive because they require no users and are relatively easy to learn, but they may miss key problems or flag false ones. Model-based methods like [[Fitts's Law]] and [[GOMS and Keystroke Level Model]] are the quantitative counterpart within this same family: they predict expert, error-free performance instead of judging against qualitative heuristics.

## Related Concepts

- [[GOMS and Keystroke Level Model]]: a complementary analytical, model-based evaluation technique
- [[Fitts's Law]]: a quantitative model-based evaluation technique, contrasted with heuristic (qualitative) evaluation
- [[Controlled Experiment]]: the user-based evaluation approach that heuristic evaluation is typically contrasted with
