WIMP (Windows, Icons, Menus, Pointer) is the dominant graphical user interface paradigm since the 1980s. It originated at Xerox PARC (Alto, 1973; Star, 1981) and was popularized by the Apple Macintosh (1984) and later Microsoft Windows.

## Components

| Component | Role |
|---|---|
| **Windows** | Rectangular screen regions that contain application content; can be moved, resized, overlapped |
| **Icons** | Small pictorial representations of objects (files, folders, applications) |
| **Menus** | Organized lists of available commands, reducing memory load |
| **Pointer** | Cursor controlled by a mouse (or trackpad/stylus) for selecting and manipulating objects |

## Design Principles

WIMP interfaces build on [[Direct Manipulation]] — users interact with visible representations of objects rather than typing commands. Key principles include:

- **Desktop metaphor** — the screen represents a physical desk with documents and tools
- **WYSIWYG** — what you see is what you get, especially in document editing
- **Recognition over recall** — menus and icons show available actions rather than requiring memorization
- **Consistency** — standard interaction patterns (close button, scrollbar, drag-and-drop) across applications

## Historical Development

1. **Xerox Alto** (1973) — first computer with a bitmap display, mouse, and overlapping windows (research prototype)
2. **Xerox Star** (1981) — first commercial WIMP system, introduced the desktop metaphor
3. **Apple Macintosh** (1984) — brought WIMP to a mass audience with an affordable price point
4. **Microsoft Windows** (1985–present) — established WIMP as the global standard

## Limitations and Post-WIMP

WIMP is less suited for:
- **Touch interfaces** — no persistent pointer; replaced by direct touch gestures
- **VR/AR environments** — 2D windows don't map well to 3D space
- **Large displays and collaboration** — multiple pointers and spatial interaction needed

Post-WIMP paradigms include multi-touch, gesture-based, voice, and tangible interfaces.
